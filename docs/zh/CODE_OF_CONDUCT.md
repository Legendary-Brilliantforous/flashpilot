## 我们的承诺

作为成员、贡献者与领导者，我们承诺让每个人都能在我们的社区中体验到无骚扰的参与环境，无论年龄、体型、可见或不可见的残障、种族、性征、性别认同与表达、经验水平、教育背景、社会经济地位、国籍、个人外貌、种族、种姓、肤色、宗教，或性取向与性别认同如何。

我们承诺以有助于建设开放、欢迎、多元、包容与健康社区的方式行动与互动。

## 我们的标准

有助于积极环境的行为示例：

- 对他人展现同理心与善意。
- 尊重不同意见、观点与经历。
- 给出并优雅地接受建设性反馈。
- 对我们错误造成的影响承担责任并道歉。
- 以社区利益为先。

不可接受的行为示例：

- 使用性化语言或图像，以及性挑逗或性推进。
- 嘲弄、侮辱或贬损性言论，以及人身或政治攻击。
- 公开或私下骚扰。
- 未经明确许可发布他人私人信息。
- 在专业场合可被合理认为不恰当的其他行为。

## 执行

若出现滥用、骚扰或其他不可接受的行为，可向负责执行的社区领导者报告。所有投诉都将得到及时、公正的审查与调查。

所有社区领导者都有义务尊重事件报告者的隐私与安全。
