# AI Advisor (beta)

FlashPilot 1.2.3 ships a read-only AI assistant that explains flashing and
lock-removal failures. It is a **beta** feature: answers are generated by an
external model and must be verified before you act.

## What it can do

- Explain why an operation failed, using the selected device, the console tail
  and FlashPilot's own operation notes.
- Discuss flashing and FRP/lock-removal methods that actually exist in
  FlashPilot (it is grounded in the live flow registry).
- Run as a dedicated **Advisor** page or a floating panel (`Ctrl+Shift+A`).

## What it cannot do

- It never runs a flow, flashes a partition or unlocks a device. You press
  every button yourself.
- It refuses off-topic requests, IMEI alteration, Knox bypass steps and
  unlocking devices you do not own.

## Providers

OpenAI, OpenRouter, Groq, Google Gemini (native API), any OpenAI-compatible
endpoint, and local servers (Ollama / llama.cpp). Configure in
Settings → AI; keys are stored in the system keyring only.

## Requirements

- A keyring backend (gnome-keyring / KWallet) for cloud providers. Local
  servers need no key.
- `operations/` shipped with the package (retrieval corpus).
