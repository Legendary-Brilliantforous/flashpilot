# Translation guide

FlashPilot uses English as the canonical documentation language.
Other languages live in `docs/<lang>/` and `operations/<lang>/`.

## Coverage

| Language | Code | UI | Docs |
|---|---|---|---|
| English | `en` | yes | scaffold |
| Français | `fr` | yes | scaffold |
| Español | `es` | yes | scaffold |
| Deutsch | `de` | yes | scaffold |
| 简体中文 | `zh` | yes | scaffold |
| Русский | `ru` | yes | scaffold |
| Português | `pt` | yes | scaffold |
| 日本語 | `ja` | planned | scaffold |
| العربية | `ar` | planned | scaffold |
| हिन्दी | `hi` | planned | scaffold |
| Türkçe | `tr` | planned | scaffold |

## Contributing a translation

1. Copy the English source file to the matching `docs/<lang>/` path.
2. Translate prose; keep code blocks, commands, paths, and identifiers in English.
3. Keep the language-switcher header at the top of each file.
4. Open a PR labelled `i18n`.
