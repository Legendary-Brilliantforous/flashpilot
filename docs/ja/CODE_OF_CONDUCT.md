## 私たちの誓約

メンバー、貢献者、リーダーとして、年齢、体格、目に見える・見えない障がい、民族性、性徴、性自認と性表現、経験レベル、教育、社会経済的地位、国籍、容姿、人種、カースト、肌の色、宗教、性自認と性的指向にかかわらず、すべての人が私たちのコミュニティでハラスメントのない体験ができるように誓います。

私たちは、オープンで歓迎的かつ多様性に富み、包括的で健全なコミュニティの構築に寄与する方法で行動し、相互作用することを誓います。

## 私たちの基準

ポジティブな環境に寄与する行動の例：

- 他者に共感とやさしさを示す。
- 異なる意見、観点、経験を尊重する。
- 建設的なフィードバックを提供し、また優雅に受け入れる。
- 自分たちの誤りの影響に責任を負い、影響を受けた人に謝罪する。
- コミュニティの利益を優先する。

受け入れられない行動の例：

- 性的な言語や画像、および性的な注意や接近。
- からかい、侮辱、軽蔑的なコメント、個人的な攻撃や政治的攻撃。
- 公開または非公開のハラスメント。
- 本人の明確な許可なく他人の個人情報を公開すること。
- 専門的な場では不適切と合理的に判断されるその他の行為。

## 執行

不当な行為、ハラスメント、その他受け入れられない行動があった場合、執行を担当するコミュニティリーダーに報告できます。すべての苦情は迅速かつ公正にレビューされ、調査されます。

すべてのコミュニティリーダーは、いかなる事件の報告者についても、そのプライバシーと安全を尊重する義務があります。
