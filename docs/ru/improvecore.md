## Прошивка ADB по устройствам
- ADB-сессии с ключом устройства: повтор/откат и понятный конечный автомат.
- Проверка после записи (хеш) по умолчанию; прогресс по разделам.
- Надёжная обработка состояний unauthorized/offline; автоматический запрос повторной авторизации.
- Поддержка нескольких параллельных ADB-устройств без перекрёстного влияния.

## Инновации Odin (Samsung)
- Превзойти последний Odin: устойчивость одной сессии, восстановление после сброса порта, стриминг нескольких разделов.
- Лучшая проверка PIT, работа с vbmeta/AVB, рекомендации по ремонту DRK.
- Возобновление/повтор при временных ошибках USB; подробные объяснения сбоев.

## BROM / низкоуровневая связь
- Единая абстракция BROM для MTK, Samsung, SPD, Qualcomm.
- Помощники crash-to-BROM, SLA/авторизация, надёжность загрузки DA.
- Классификация ошибок с практическими исправлениями; таймауты на каждом этапе.

## Поддержка новейших MTK
- Разбор preloader V5/V6 и выбор DA (`mtk_daloader.rs`).
- Отслеживание новейших версий DA/preloader MTK; автоопределение и выбор.
- Обеспечение работы путей exploit/SLA на новейших чипах; добавление тестовых фикстур.

## Обнаружение USB-интерфейсов
- Обнаружение CDC ACM, ECM/NCM, mass storage, HID, vendor-specific, diagnostic/modem.
- Обнаружение bootrom, preloader, ADB, download mode, EDL, MTK, SPD.
- Вывод списка интерфейсов в строках устройства; сопоставление с поддерживаемыми потоками.

## Мгновенное удаление (FRP/MDM/блокировки)
- Исследование интеграций вроде HiProTool: быстрые пути там, где безопасно, задокументированы.
- Плейбук по устройствам в `operations/` с проверенными шагами.
- Сохранение экспериментального шлюзования + аудит-лог для рискованных операций.
